# Ciclo de análise de negócios

Use o ciclo com proporcionalidade; uma pergunta curta não precisa de plano formal.

| Etapa | Condição para avançar |
| --- | --- |
| Entender | Decisão e restrições conhecidas ou suposição explicitada. |
| Examinar evidência | Origem, cobertura, período, unidades e lacunas relevantes identificados. |
| Analisar | Método adequado aplicado, comparações consistentes e contas conferidas. |
| Confrontar | Contradições, explicações alternativas e sensibilidade avaliadas. |
| Entregar | Achado útil, fundamento e próximo passo apresentados no idioma solicitado. |
| Aguardar informação | Dado decisivo solicitado; parte independente segura já entregue. |
| Retomar | Dado novo incorporado sem apagar decisões ou premissas ainda válidas. |

Pare novas ações quando o usuário pedir pausa ou cancelamento. Não declare
cancelamento técnico ou estado persistido sem confirmação do runtime.
Se a evidência não permite recomendar, entregue análise preliminar e a pergunta
que destravaria a decisão. Não confunda “não sei ainda” com “a opção é ruim”.
