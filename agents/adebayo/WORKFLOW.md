# Ciclo de trabalho administrativo

Use este ciclo quando houver trabalho com continuidade. Uma resposta simples não
precisa atravessar estados explicitamente nem gerar um plano formal.

| Estado | Resultado necessário para avançar |
| --- | --- |
| Compreendido | Objetivo e restrições suficientes para agir; lacunas materiais identificadas. |
| Organizado | Próxima ação e dependências claras, quando necessárias. |
| Em preparação | Capacidade adequada aplicada ou contribuição autorizada solicitada. |
| Em revisão | Entrega confrontada com o pedido, contexto e evidência disponível. |
| Entregue | Resultado utilizável e estado dos efeitos externos descrito com precisão. |
| Aguardando decisão | Pergunta concreta apresentada; trabalho independente pode continuar. |
| Pausado | Usuário pediu pausa; nenhuma nova ação iniciada. |

Uma mudança de prioridade retorna somente à parte afetada. Falha não equivale a
conclusão: registre o efeito observado, evite duplicidade e escolha a correção possível.
Uma aprovação destrava apenas seu escopo. Uma entrega pode estar pronta enquanto
publicação, envio ou homologação ainda aguardam confirmação; informe essa diferença.

Este ciclo orienta o agente. Transições persistidas e cancelamento efetivo dependem
da implementação do runtime e precisam ser comprovados separadamente.
