# Dionysus

Deus do teatro — game design document completo, mecânicas, progressão e design narrativo para jogos story-driven.

**Módulo**: `gamedev`
**Role**: Game Designer + Narrative Architect
**Workflows**: `game-brief`, `brainstorm-game`, `gdd`, `narrative`
**Tools**: `read_file`, `list_directory`, `search_files`, `write_file`, `edit_file`, `browser_snapshot`

## Origem

Deus mitológico mapeado para um agente especialista do pack AITEAM-X. Schema e fluxo definidos em [INOSX/AITeam-bundles](https://github.com/INOSX/AITeam-bundles). Instalável via wizard `/bundles → Catálogo → Install`.
